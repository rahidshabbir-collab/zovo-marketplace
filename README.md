# ZOVO Marketplace — starter demo

This is a front-end starter for the ZOVO international multi-vendor marketplace concept.

## Run it
1. Extract the ZIP file.
2. Open `index.html` in a modern browser.
3. For local development, you can use VS Code with the Live Server extension.

## Included
- Responsive premium dark/navy + gold homepage
- Product search and category filtering
- Demo product cards
- Working cart drawer and quantity count
- English/Urdu text toggle
- Demo seller profile form
- 5% commission messaging

## Important limitations
This is a **front-end demo**, not a production marketplace. It does not yet have:
- Real customer/seller accounts or secure authentication
- Database storage or image uploads
- Seller product management dashboard
- Real order processing or shipping integrations
- Payment gateway, escrow, payouts, or automatic 5% commission settlement
- Admin moderation and fraud controls

Do not accept real payments or collect sensitive customer information with this demo. A production marketplace needs a backend, database security rules, seller verification, payment-provider approval, legal/tax review, and testing. Payment-provider availability varies by country.
